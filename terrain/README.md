지형 데이터는 mwmap/terrain/manifest.json의 `mode`가 `팀 데스메치`인 원본 15종입니다.
mwmap/indexbh.js의 modeLabel은 이 mode를 그대로 표시하고, 맵 선택은 해당 variant의 slug를 사용하며, 지형 로더 jV는 dataFile을 읽습니다.
파일명 `_dm`은 도미네이션에 연결되므로 포함하지 않습니다.
manifest.json은 팀 데스메치 항목만 남겼으며 높이 데이터는 수정하지 않았습니다.

- little-endian unsigned 16-bit, 513 × 513
- 높이(m) = altMin + raw / 65535 × (altMax - altMin)
- mwmap처럼 원본 Z 행 순서를 뒤집어 표시합니다.
- 시뮬레이터에서는 맵 중심을 (0, 0)에 두고 가로·세로·높이에 같은 배율을 적용합니다.
- 기본 배율은 원본의 10배이며 슬라이더 범위는 0.25~20배입니다.
- 플레이어는 양 팀의 `standard` 스폰 중 함체가 지형에 겹치지 않는 위치를 무작위로 선택합니다. 원본 스폰 좌표와 방향에 지형과 같은 좌표 변환을 적용합니다. 극단적으로 축소하여 모든 스폰이 막히면 무작위 스폰 주변의 가까운 안전 해역으로 보정합니다.
- 원본은 높이 격자이므로 각 X/Z 좌표에 하나의 지표 고도가 있습니다.
- 해수면은 mwmap의 실제 고도 0m이며 음수 고도는 해저입니다. 지형 배율은 이 해수면을 기준으로 적용합니다.
- 함선 이동·표적 경로·스폰 검사에서는 고도 0m 초과의 육지만 장애물로 취급하며, 수중 지형에는 충돌하지 않습니다. 격자 거리 계산은 빠른 통과 검사에만 사용하고, 경계에서는 실제 렌더링 삼각형을 수면 기준으로 검사합니다. 플레이어는 회전된 실제 선체 바닥 모양으로 충돌을 판정합니다.
- 플레이어 충돌은 속도의 10% 감속과 진행 반대 방향으로 최대 3m 반동을 적용합니다. 반동 구간도 충돌을 검사하며, 같은 접촉은 0.2초 간격으로 처리해 프레임마다 감속이 중첩되지 않게 합니다.
- 레이더와 미사일 탑뷰는 북쪽(-Z)이 위인 고정 방향이며 함선 아이콘과 시야 표시만 회전합니다.
- `playableBoundary`의 `MapConstrains/Constrain` 공기장벽을 지형과 동일한 중심·Z 반전·배율로 변환합니다. 플레이어·표적의 함체, 스폰 및 이동 경로가 경계 밖으로 나가지 않게 하며 미니맵에 점선으로 표시합니다. 함선이 들어갈 공간이 없는 배율 변경은 적용하지 않습니다.
- 표적은 플레이어로부터 1~3.5km 이내의 무작위 해역에 생성합니다. 함체 전체의 해안 여유 공간을 검사하며, 안전한 위치가 없으면 생성을 보류하고 재시도합니다.
